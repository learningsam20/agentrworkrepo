# Single-player Ludo

A simple single-player web-based Ludo game (player vs AI) implemented with HTML, CSS, and JavaScript.

How to run:
1. Open ludo/index.html in a browser.

Features:
- Basic board and 4 tokens for player and AI
- Dice roll
- Simple AI that moves the first possible token

Notes:
This is a minimal implementation intended as a starting point. Further improvements: animations, rules completeness, AI strength, tests.
